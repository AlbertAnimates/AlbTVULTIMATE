🛠️ How to Use

1. Download the Playlist

Clone the repo or download the raw M3U file:

```bash
git clone https://github.com/Albi/AlbertAnimates.git
```

Or download TV.m3u directly from your browser.

2. Open in Your Favorite Player

· VLC Media Player: File → Open File → Select .m3u
· TiviMate: Add playlist → Enter URL or local file path
· Any M3U‑compatible app: Just load the file and start watching

3. (Optional) Use the Web Player

Open top_tul.html in your browser to test streams directly.
